# Candidate 602: Ubuntu 26.04 XFCE X11 focused probes

The unmodified AppImage SHA-256 `602dab02b4837bb8d30c864dbe50d0413d58d53afb53d9695c7f96f50cdfb756` was verified inside the guest; no packaged source was overlaid, and the three relevant module hashes were captured in `run.log`. Ubuntu 26.04 used an active XFCE X11 session in a network-isolated KVM container with original and backing disks mounted read-only and a temporary QEMU snapshot. The login-session change to XFCE and X11 was made only in the disposable snapshot. `session.log` records `Type=x11`, `State=active`, `DESKTOP_SESSION=xfce`, and `XDG_CURRENT_DESKTOP=XFCE`; the runner passes the same desktop value. No host user credential directory was mounted. The test used temporary Fcitx configuration, owned GTK controls, fixed synthetic input, and stubbed audio/transcription.

In `run.log` the automatic and explicit Fcitx full samples each delivered exactly 200 characters, and each cancellation sample retained one character then ended cancelled. The simple-module target produced certain zero-prefix Fcitx `no_target` (`accepted=0`, `offset=0`, `uncertain=false`); the packaged X11 keyboard was invoked, delivered all 200 characters and succeeded. All five fixture `passed` fields were true. Observed D-Bus daemon replies had sender `org.freedesktop.DBus`; Fcitx RuntimeVersion/Begin/Commit/Cancel responses matched pinned owner `:1.44`. One sender tuple is logged per distinct method/destination/sender, not per message.

Reproduce by copying these exact scripts (remove `.txt`, name the sender `sender.py` and target `target-focus.py`) and the exact AppImage into `/tmp/inkecho-r4-test` in an isolated active XFCE X11 guest, then run `bash probes/run.sh 602dab02b4837bb8d30c864dbe50d0413d58d53afb53d9695c7f96f50cdfb756 x11`. The runner hashes and extracts the package and uses a private Fcitx profile. It does not edit packaged code. The guest received QMP system_powerdown; docker wait returned 0, and the container was removed.

These single controlled samples do not establish arbitrary applications, focus races, IBus, physical shortcut, real microphone, cloud recognition, GNOME X11, Ubuntu 24, or complete package acceptance. The package remains a candidate.
