# Private D-Bus Fcitx preflight close timing

2026-10-29; a private `dbus-run-session` bus and synthetic service implement the Fcitx bridge interface. The real Python `Fcitx5Bridge` and `OutputRouter` call that service, which deliberately delays `Cancel` by 5 seconds. The detector is synthetic and blocks during its second owner check; no real input method, desktop, recording, provider or Commit is used. The private service is not the real Fcitx daemon/plugin.

`before-real-r2.log` records baseline: task deadline 0.2 s, outcome expired after 3.203 s; service observed one Begin and one Cancel, zero Commit, no keyboard connection; bus and capability closed, client's unique bus owner gone. `after-real.log` records the same probe with the proposed source patch: expired after 0.201 s, one Begin, zero Cancel, zero Commit; bus and capability closed, client unique owner gone. `before-real.log` is the first baseline run, which produced the expected 3.204 s result and an event-loop traceback from cancelling the delayed test-service coroutine during shutdown; r2 waited for the test service to finish and is the clean baseline. `before.log` records the initial sandbox refusal to bind a private bus socket; the subsequent runs used an approved isolated local bus. Time values are one local sample each, not universal latency guarantees.

The proposed separate `/tmp/inkecho-fcitx-abort-preflight.patch` disconnects only an auto preflight bridge that has never attempted a Commit and is not busy; normal, already-sent and uncertain paths retain existing Cancel cleanup. `before-unit.log` records the new tests failing against baseline. `after-unit-r2.log` records 121 router/bridge unit tests passing, including attempted/uncertain-send refusal, cleanup error sanitization and cancelled/expired preflight. The actual plugin's `native/fcitx5/inkecho.cpp` registers a unique-owner ServiceWatcher and calls TaskGate owner_lost on disconnect. The private test proves D-Bus owner disappearance, not that the real plugin has already processed its watcher; disconnect and watcher handling are asynchronous, so a new task immediately after abort can temporarily be rejected. This experiment does not prove real-plugin lifecycle timing, any target input behavior, no replay across all races, or package acceptance.

Reproduce locally only on a private temporary D-Bus: copy the probe without `.txt`, select baseline or patched independent source through `PYTHONPATH`, and run `dbus-run-session -- python probe.py`. The probe creates a transient service and uses a fake capability token, never a real key. Its delayed Cancel waits 5 seconds and a cleanup wait is deliberate; stdout's measured interval excludes service teardown.
