# Ubuntu 24 / 26 Xorg 对端进程与登录会话探针

2026-10-30，在隔离 Ubuntu 24.04.5 和 26.04.1 客机上顺序开展只读 Xlib 连接与 logind 查询，未发送按键或文字、未使用剪贴板，也未运行或修改 InkEcho 产品。

24 的 GNOME Xorg 与 XFCE Xorg 样本中，已建立的 Xlib 连接的 Unix socket 对端均为当时的 Xorg 进程，logind 查询将其关联到同次观察中的活动 X11 登录会话。XFCE 会话随后反复退出和重启；桌面管理器的环境提示仍保留先前的 XFCE 信息，不能将该采样推广为持续稳定状态。

26 的 XFCE Xorg 样本中，Xlib 连接对端为当时的 Xorg 进程，logind 将其关联到一个活动、本地、同用户的 X11 图形会话。该会话和连接属性是分别读取的，检查并非原子操作。当时用户总线进程没有可关联的 logind 会话。

两系统均启动自有 Xvfb 作为非目标显示服务：连接对端是该 Xvfb 进程，logind 将它关联到测试用终端会话，而桌面管理器环境仍显示 XFCE。24 的 Xvfb 对照发生在先前 XFCE 会话已结束之后；26 的对照期间，先前 XFCE 会话仍存在。此对照说明桌面管理器环境不能单独证明实际连接属于活动桌面，不证明所有其他场景均可被区分。

两台客机和容器均正常退出、未发生 OOM。取证快照保留 XFCE 会话选择；原始父镜像及宿主未修改。完整原始证据仅保留在本地，不随此报告提交。

这些样本说明，在所测 Xorg 环境中，已连接 socket 的对端进程与 logind 信息可以提供会话关联线索；它们并不证明所有 Xorg 或 Xwayland 部署的对端身份相同，也不证明 Xauthority 对服务端的身份认证，更不能单独将用户总线绑定到图形会话。会话或焦点可能在检查后变化，当前没有目标级原子检查，不能据此放宽自动回退或重放保护。
