# Fcitx 自动检测的 XDG 数据目录处理

`XDG_DATA_HOME` 未设置、为空或为相对路径时，应使用用户的 `~/.local/share`；此前空值会被当作当前目录，相对值也直接使用。若正常安装的 Fcitx 输入桥位于默认目录，自动检测因此找不到已安装桥并可能回退键盘。修正只改变目录选择；显式指定的目录、有效绝对 XDG 目录、输入桥验证、焦点、拼音保护和不重放策略不变。

2026-10-30 本地验证：`ruff check` 和 `ruff format --check` 对修改文件通过；`pytest -q tests/test_fcitx5_install.py tests/test_fcitx5_staging.py tests/test_framework_detection.py` 共 72 项通过。新增测试覆盖未设置、空值、相对值、绝对值及显式覆盖；使用实际安装器写入测试用桥文件，再通过 `auto_version()` 验证默认目录能够被发现，而不同的绝对目录不会误读默认桥。系统版本和文件哈希在测试中受控，不代表实际桌面环境验证。首轮格式检查发现新增测试行过长；补充文件回归时重构测试的首轮检查发现变量作用域与格式错误，修复后全部重跑通过。

这些是本地自动化检查，不是实际 Ubuntu 桌面或 AppImage 验收。此修正没有解决其他已记录的原生 IBus 到 XWayland 中途停止问题，也不应据此宣称全部输入法组合受支持。
