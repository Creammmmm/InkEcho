# Ubuntu 24.04 isolated IBus context identity probe

Ubuntu 24.04.5 was run in an independent, network-isolated QEMU `-snapshot` guest; original disk and base images were mounted read-only. A private session D-Bus and private IBus daemon were started using the included exact probe scripts. The scripts did not inspect or alter the desktop IBus session, switch input methods, query surrounding text, send text, or read user content. The client context is created by the probe, not by a real text widget. The guest was shut down normally, Docker wait returned 0, and the container and temporary VM SSH key were removed.

`ubuntu24-probe.log` shows both IBus's fake current context and a separately created client context with matching focus/preedit/surrounding capability flags declared the same four D-Bus properties: `ClientCommitPreedit`, `ContentType`, and `EffectivePostProcessKeyEvent` are write-only; `PostProcessKeyEvent` is readable but deliberately not read because its queued data may contain text. Queries for `Client`, `ClientName`, `Fake`, and `Capabilities` returned the same `org.freedesktop.DBus.Error.InvalidArgs` for both contexts. Probe exit was 0; actual script hashes are in the log.

For reproduction in an isolated 24.04 guest, copy `run.sh.txt` and `probe.py.txt` to the same temporary directory as `run.sh` and `probe.py`, then run `bash run.sh`. No graphical session is required. The daemon exits and its temporary files are removed by the script.

This supports only the narrow conclusion that these tested public properties do not distinguish the daemon's fake context from this synthetic client context in the tested version. It does not prove that all possible interfaces or desktop configurations lack usable signals, that a focus check would be race-free, or that client delivery can be acknowledged. In the separate GNOME X11 button experiment, attempts returned without text delivery; an unverified assumption that a nonempty context represents a real receiver would silently lose text. No product code or automatic IBus selection is added on this basis.
