# Repeat: IBus panel focus and stale cursor metadata

On the host with IBus `1.5.34-rc2`, this probe was run with an empty environment, a private `dbus-run-session`, a private IBus daemon bound to a temporary socket, temporary HOME and runtime directories, and no DISPLAY. The script uses a synthetic context and rectangle; it does not query or alter the desktop session, input method, user content or clipboard. It terminates its own IBus daemon and removes its temporary directory. This is a private-bus test, not a virtual desktop or packaged application test.

`private-bus.log` shows a synthetic context focused and reported a cursor rectangle `(11,22,3,4)`, followed by fake-context focus without a clearing cursor event; a subsequent unfocused-client cursor update produced no event. A cached last rectangle therefore does not establish a current real receiver. A focus-bound cache might avoid this particular stale value, but has not been proven to establish target identity or cope with asynchronous transitions. A portal autoactivation in the private bus failed, also recorded in the raw log, while the probe's assertions passed.

The first `sandbox-failure.log` records a failed invocation because the sandbox denied the private D-Bus socket bind; no test ran in that invocation. The successful run used `env -i PATH=/usr/bin:/bin HOME=/tmp LANG=C.UTF-8 bash run.sh` with sandbox escalation. The scripts are identical to `experiments/ibus-cursor-metadata-ubuntu24`, saved with `.txt` suffixes. SHA-256: run `a075c81cbfa4b654eea804189b91a25d98c794b3b72d960d8274586915daf2a0`, probe `6487aa8890a3a5dbf41de2a58981b221fe79b1b6af0767e564dd13c2307134f0`.

Existing real GNOME desktop evidence in `experiments/ibus-focus-gtk-module-ubuntu26` shows `currentFocus=false` for actual receiving GTK IBus text fields, and `experiments/ibus-atspi-metadata-ubuntu26` shows editable accessibility metadata does not distinguish simple and IBus entries. Combined with fake context and focus races, none establishes a reliable general zero-prefix no-target classification or an atomic delivery acknowledgement. No automatic IBus route, fallback after attempted delivery, or production change is justified by these samples.
