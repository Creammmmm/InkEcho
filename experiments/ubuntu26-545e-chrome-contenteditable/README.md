# Candidate 545e: Chrome contenteditable, Ubuntu 26 Wayland

Network-isolated Ubuntu 26 GNOME Wayland was active and unlocked. Parent image, base and Chrome directory were mounted read-only; the local Chrome profile and test content were disposable. Exact AppImage SHA-256 `545e07e080f05b90fdec4216edf8ff10e3acf6167af3ef505b6fd0a351401c06` was verified; packaged code and IBus extension were used without overlays. Chrome 154.0.8037.97 ran via XWayland with a synthetic HTTP contenteditable. The packaged Session used explicit IBus and a synthetic recorder/transcription; no real credentials, provider requests or clipboard were used. The `websockets` 15.0.1 package is test-only, copied from the previous isolated probe and is not product code.

The full sample activated the real Chrome window; page focus was true and both input event observations and a separate DevTools DOM read saw the exact 200-character synthetic text. Session reported `unconfirmed` with `ibus_delivery_unknown`, not confirmed delivery, as expected for this explicit IBus interface. The cancellation sample sent SIGUSR1 to call Session.cancel after the page's first observed input. The handler saw 30 confirmed attempts and a 31st Commit had already started before the handler timestamp. Final focused DOM held 31 characters of the expected prefix; input event for character 31 arrived after the handler, consistent with that in-flight request. Periodic page snapshots remained at 31 through the last recorded sample; no subsequent Commit started after cancellation in the recorded sender trace. This is one bounded observation, not a guarantee for every race.

Scripts are preserved as `.py.txt`; replay requires renaming and providing the test-only websockets dependency. GNOME extension was disabled/deleted in the disposable guest; the guest shut down normally and the isolated container and overlay were removed. This test does not validate Ubuntu 24 Chrome, normal Chrome sandbox/profile, actual online websites, Fcitx/auto selection, real microphone or cloud, arbitrary switching, or package/release acceptance.
