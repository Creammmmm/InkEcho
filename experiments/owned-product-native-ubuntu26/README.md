# Product candidate with GNOME native GTK target: Ubuntu 26 source-level check

2026-10-29. Frozen product candidate source archive SHA-256 8409541cffa3e14600d18b5fd33d1159a176d9e349719baa0efea68c788c1c51, integration patch SHA-256 00efcb77599e820a688c8be1dda40985ba44d00e1e089fe0f83249b5a122ef5a. This overlays source into an older AppImage runtime to run tests and is not package or release acceptance. Ubuntu 26.04.1 GNOME Wayland was launched in a separate network-disabled Docker container with QEMU snapshot; original disk/base/seed and script/runtime shares read-only, output temporary. No SSH key, credentials, real audio, clipboard or network were used. QMP was restricted to guest's run dialog. Guest shutdown was normal, container exited 0, OOMKilled false.

The real settings CompatibilityPage selected owned_auto, installed the candidate extension (initially not discovered) then, after guest reboot, enabled it and Shell reported ACTIVE with disk content verified. The settings page methods ran programmatically; this is not pointer click or visual layout testing. Target process used the default GTK input context (GTK_IM_MODULE unset) to exercise Shell-owned native Wayland; the sender process environment is distinct. The real Session used synthetic recorder/transcription and a self-owned GTK3 target.

- Full: backend ibus; actual GTK target received the exact 200 synthetic characters, no keyboard authorization events; Session reported unconfirmed, not confirmed receipt.
- Cancel: backend ibus; cancellation triggered after first arrival; observed two-character prefix and final cancelled state. One character may have already been in flight; no further text was observed after the harness's 1.3-second wait. Programmatic SIGUSR1, not physical Esc.
- No target: active/focused non-text button; backend keyboard; both text fields empty, final succeeded means attempts sent and does not prove receipt. It is not an IBus result.
- Settings CompatibilityPage disable method reported installed but not running; gnome-extensions reported INACTIVE / Enabled No.

The retained target fixture's `passed` field applies an obsolete Fcitx-only assertion, so actual contents, route events, outcome and focus fields establish these observations instead. Only one GTK3 native target was tested; no Ubuntu 24, GTK-owned IBus, live audio/cloud, physical hotkey, arbitrary applications, adversarial service replacement, in-flight uncertainty, or exact same-package dual-system verification. Disk hashes and Shell status cannot authenticate the code currently in Shell memory. Version check reads installed Shell executable rather than proving running session version.
