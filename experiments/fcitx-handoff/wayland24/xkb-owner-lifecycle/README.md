# GNOME 46 临时映射所有权实验

仅阶段 0 探针，不是产品补丁。Ubuntu 24.04.5 GNOME 原生 Wayland，独立 QEMU `-snapshot`，基础盘、seed 及测试输入只读，无外网；不挂载宿主密钥目录或用户桌面。临时扩展的 D-Bus 接口没有调用权限保护，绝不适用于生产。为使 GDM 使用 Wayland，启动后仅在快照里切换登录配置并重启客机会话，`loginctl` 报告 active/wayland。GTK3 原生 Wayland 测试框聚焦。仅用 Shell 模拟键盘，不涉及剪贴板。

扩展绑定 D-Bus 唯一连接；获取期间拒绝第二个连接，设置变化时结束会话，只有原连接可发键或恢复；监听连接消失，在当前 Shell 键盘参数仍与取得所有权时一致时尝试恢复。在 `result-r3.log`：连接 A 获得所有权，连接 B 的获取和发键被拒，A 输入“甲”；受控修改键盘选项后 A 不能继续发键，B 获得所有权并输入第二个“甲”；B 连接关闭后，A 能取得所有权并输入第三个“甲”，最终 GTK 内容为 `甲甲甲`，配置保留 `caps:escape`。这是两个连接顺序调用和连接正常关闭的测试，不是进程强杀或真正并发。

XWayland 导出的映射摘要在配置变化后、连接失联后和最后主动恢复后均为 `ded2a09c3a818e7722565c9b7b328b06fb04d8bd41ca526f41098cdb1b8a5d87`；B 持有临时映射期间为 `b917e999c7191d95185aaa2fc9b668f8d84b5cade590cb662193629f0f935d95`。`xkbcomp` 报告缺少 geometry 警告，这只是 XWayland 的导出，不证明原生 Wayland 客户端完整映射恢复。第一次 `result.log` 的导出缺少 X 授权导致失败，`result-r2.log` 修正了授权但未记录配置更新后的基线，均保留。扩展和最终测试脚本保留以便复现。

`cleanup.log` 显示测试扩展已停用、测试选项为空；之后移除快照内扩展与临时 XKB 文件并请求客机关机。没有宣称所有设置逐项恢复。

## 限制

该探针仍不能用作产品：`_currentKeymap`、`set_keymap` 等是 GNOME 私有接口；外部改动可能绕过 GSettings 或管理器，不能作可靠比较。设置变化信号与实际后端映射变更不构成原子事务，配置更新可发生在发送检查和按键之间；全局映射影响物理键盘。未测试 Shell 崩溃、进程强杀、不同扩展竞争、多个真实进程同时抢占、物理按键和切焦，也未证明按键和接收完成。所有权锁只协调这个实验扩展，不能约束其他程序写全局映射。不得据此宣称 24.04 Wayland 回退已修复。
