# 私有 IBus 中预编辑与面板提交顺序

2026-10-29 在 Ubuntu 26.04.1、IBus `1.5.34~rc2-1` 和 ibus-libpinyin `1.16.5-2` 上测试。本实验使用独立 D-Bus 会话、私有 IBus daemon、临时 HOME 和专用输入上下文；仅处理自造按键及自造文字，不接触用户会话、输入法、剪贴板或正文。保留实测原始探针为 `probe.py.txt`；复现时将 `run.sh` 与该文件复制至同一个临时目录，将后者更名为 `probe.py`，再执行该目录中的 `bash run.sh`。该复制和重命名后的步骤尚未重跑。受限沙箱须允许创建本地 Unix socket。脚本在临时目录中启动引擎和配置服务并在退出时清理。

合成 `n`、`i` 后产生可见预编辑，面板提交固定字符“甲”，接着合成空格；观察到两次提交内容依次为“甲”和“你”，引擎仍为 libpinyin，进程退出 0。日志保留 GI `g_object_is_floating` 警告、缺失临时 Lua 配置和缓存文件提示。

此结果仅证明此私有上下文中的信号内容和顺序，并未验证真实窗口的光标、显示或预编辑交互，未测试焦点变化、其他引擎、Ubuntu 24.04 或 AppImage；也不能证明目标已处理文字或安全启用 IBus 自动选择。目标不明的提交不可重放。
