# Candidate 32f: Ubuntu 24 Wayland GNOME Terminal

Original AppImage SHA-256 `32f20808a0143d61bf24b2809a11d47344688a7e7edb690684f9e47cfd50bfa5`, without source overlays. This candidate precedes the later IBus confirmed-no-service fast-close fix and does not include it. A disposable KVM overlay used read-only original disk, base and seed; the environment had no external network. Session setup and tests affected only the guest. Session inventory and extension hashes are in `guest/*.log`. Test programs use synthetic audio and transcription and a disposable credential, not actual host data, real credentials, microphone or providers.

The test launches GNOME Terminal with a custom raw-mode reader, not a real shell or CLI. Its Wayland versus XWayland client backend is not established. On the Fcitx route the full test received 200 characters exactly, cancellation retained only the first character at both cancellation and completion, and controlled switch delivered first character to terminal A and remaining 199 to B exactly. The probe injects a 25ms delay per Commit; it does not measure production speed. Cancellation is triggered via a synthetic signal, not physical Esc. Switch pauses the sender before opening B and resumes after a delay; B's focus was not independently measured and this does not test unpaused focus races.

For explicit IBus, the unmodified package's extension was installed only in the guest and reported ACTIVE. The same terminal fixture received all 200 characters; the application reported `ibus_delivery_unknown` and task failure, because IBus provides no target receipt acknowledgement. This does not show confirmed delivery for other targets, nor any IBus service disappearance or no_service behavior. The Fcitx session environment was cleaned up first; for the IBus run the isolated terminal server was restarted and guest environment restored.

Raw scripts are archived as `.py.txt`; restore the suffix only in a disposable guest with matching original candidate on a read-only 9p share. Scripts change test guest configuration and must not be run on a user desktop. The guest extension was disabled/deleted before normal poweroff. These samples do not establish real speech, browser, actual shell/CLI behavior, Ubuntu 26, or full release/package acceptance.
