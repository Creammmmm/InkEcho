# 概览布局与自动余额验证（2026-10-21）

## 本轮行为

概览顶行分别展示今日发送字符（Unicode 码点）、录音分钟数和使用次数。
下方左列为最近七天每日发送字符柱状图，右列为当前语音及润色模型配置，
每种配置的右侧显示余额状态，下一行提供已知官方控制台入口。
关闭云端润色后，相关配置和余额灰显，且不读取该配置的认证字段。
窄图表日期使用 12 像素的「15日」短标签，完整年月日和精确字符数保留在悬停提示中；
柱顶极长数字在单格内省略，避免邻格互相覆盖。余额和控制台提示允许窄列换行，
不强迫页面出现横向滚动。没有适配余额接口时明确显示未知；本地统计或 Token 不作为真实账单。

进入可见概览自动查询，成功、失败和未知结果均在内存中缓存五分钟，
同一页最多存在一个自动查询任务。再次进入页面可复用未过期缓存；
配置或凭据文件变动使缓存失效。切换配置取消旧任务，离开页面、隐藏或关闭
窗口停止定时器并取消请求。每个配置的凭据加载与余额读取合计最长十二秒，
复核页面修订号及配置快照后才允许刷新标签；不记录密钥或远端异常正文。

余额接口继续使用已有适配：只对 OpenAI 适配器且完整地址为官方 DeepSeek
根地址或 `/v1` 的配置读取密钥并查询固定 HTTPS 只读余额地址。
自定义网关不会把其密钥发送到官方接口。其余平台只展示已知官方控制台链接，
没有已知链接时如实标明，未增加未核实的余额接口。
