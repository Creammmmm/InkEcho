## 本轮变更与现有实验边界

统一控制器区分 NONE、INPUT 和弱 DRAW 提示；Xorg 输出按实际映射成本和进展进行
有界节流，原生 Wayland 保留单请求在途和既有映射/释放时序。取消、任务替代、绝对
截止时间、当前光标语义、映射所有权及清理保护保持不变，不使用剪贴板或系统输入法。

[自适应源码验证](adaptive-output-validation.md)保存了完整原始实验入口及失败门：

- Ubuntu 24.04.5 / Mutter `.18` 的自建 GTK3 20ms 基线已顺滑，未复现旧 `.15` 的整句卡顿。
- 38 字候选末尾绘制间隔约 204.35ms，超过预定 200ms 目标，不能写成全部性能验收通过。
- 114 字候选相对同长度 60ms 基线发送跨度缩短 38.27%，仅各一例，缺同长度 20ms 对照。
- 首字后取消独立接收器持续观察约 1.36s 无尾部正文；这不是物理 ESC 实测。
- 250ms 尾部 hold 仅存在于实验 probe，全文在 hold 前已绘制，不支持加入产品固定等待。

这些均是源码受控实验，不是 0.10.0 包验收。XWayland DRAW 保持禁用，原生 Wayland 新
INPUT 路径的 Ubuntu 26.04 本轮实测尚缺；输入 ACK 不是目标绘制或呈现确认。
第三方应用、实际焦点切换、负载及其他桌面版本矩阵未验，不宣称全面修复。

## 独立桌面环境准备

Ubuntu 24.04 使用专用完整 GNOME / Xorg 桌面，实际发行版、GNOME、Mutter、工具包和
输入后端须重新记录；不继承上次 VM 源码实验或旧包验收。GNOME 46 原生 Wayland
缺少既有所需 API 的历史结果保留，不将 Xorg 验收写成 24.04 原生 Wayland 支持。

root 正在准备全新的 Ubuntu 26.04 完整 GNOME 虚拟 seat 隔离 VM，而非用 headless、
容器 offscreen 或单个嵌套测试窗口替代实际桌面。环境尚未就绪/验收；必须先核对实际
OS、GNOME/Mutter 版本、活动原生 Wayland 会话及所需 API，再进行键盘门。若该 API
不可用，应如实报告阻碍，不把模拟 worker 结果当作原生支持。

只向新建、已审查 PID/start-time/backend/空白状态的自有接收窗口发送固定公开文本；
在每次发送前核对任务与当前目标，保留 keys_held 防护。截图仅限自有窗口，不读取真实
凭据、不发送真实云请求、不操作宿主用户桌面。物理快捷键等未经实测时单独标记。

## 同一 AppImage 的必需门

两系统必须选择同一精确产物，保留原始进程等待和失败证据，先完成完整 artifact/source
审计，再运行实际包；不允许源码 overlay 或旧版本 Python 冒充所选包解释器。

| 实际检查 | Ubuntu 24.04 完整桌面 | Ubuntu 26.04 完整桌面 |
| --- | --- | --- |
| 同版本 / SHA / inventory / 全部源码与模块 origins | 待验 | 待验 |
| 实际 AppImage 启动、设置各页、图标身份、单实例与关闭/退出 | 待验 | 待验 |
| cold toggle/cancel/quit 不复活进程，私有配置保持 | 待验 | 待验 |
| 供应商协议与 Qwen realtime 选择、本地 TLS/WSS/SSE 链路 | 待验 | 待验 |
| 实际 Recorder 虚拟音频首帧、状态动画与草稿边界 | 待验 | 待验 |
| 混合 Unicode 当前光标输出、可信中间前缀与最终准确性 | 待验 Xorg | 待验原生 Wayland；XWayland 单列 |
| 部分输出取消后至少 1.2s 无尾部正文、无歧义重放 | 待验 | 待验 |
| 焦点/后端变化、旧反馈隔离、任务过期与固定 deadline | 待验 | 待验 |
| 按键平衡、keymap/group/modifiers 恢复、观察对象与进程清理 | 待验 | 待验 |
| 新 Xorg DRAW 能力、缓存/实际映射、反馈丢失/NONE 降级 | 待验 | 不外推 XWayland DRAW；禁用状态须核验 |
| 新原生 INPUT RTT/ACK 与非法辅助反馈兼容 | 不冒充 GNOME46 原生支持 | 待验，不能用 ACK 代替 DRAW |

对变更路径补短句/长句、重复字符、实际映射与缓存对照，记录首字两种起点、发送跨度、
间隔分布、最大绘制停顿（覆盖到完整正文，不截尾）、map/MappingNotify 次数及清理。
预定 200ms 门槛不因候选失败而调整；同环境比较才能计算性能增减。不以每字一帧作为
唯一判据，不用最终文字正确代替连续可见推进。

实际目标逐项注明 GTK3/GTK4、浏览器、终端等，未覆盖的用户应用保持未验。实时 ASR
草稿与最终输出分开，普通协议不伪造 partial；未识别到内容静默，真实错误仍准确反馈。

## 系统库、集成及未测能力

当前配方不捆绑 `libXdamage.so.1`、`libXext.so.6` 或 `libX11.so.6`。新适配器从系统读取
可用库，计数器/Damage 分别缺失时按实际能力降级至 counter-only、damage-only 或 NONE；
包验收须记录实际库 origins 与降级行为，不能声称已打包或两库总存在。没有新增 Python
wheel 依赖；新产品模块随整个 `src/inkecho` 入包，完整 inventory/source 审计必须包含。

实际 FUSE、Dock/窗口图标、安装/路径修复、自启动、物理麦克风、物理快捷键/ESC、overlay
焦点和真实云服务各自单列实际结果或未验，不从本地协议、虚拟音频、源码测试外推。
26.04 若仅验自解压 AppRun，不能写成 FUSE 通过；仅 host 库兼容不能冒充双系统桌面。
