# Wayland 混合键盘派发统计验证

2026-10-31，扩展取消和失败时的派发下界统计：原生 Wayland worker 的 `key` 回复经数量和时间字段验证后计入；GNOME Wayland 的 Hybrid 键盘在原生与 XWayland 后端切换时累计已完成作用域和当前作用域的下界。有效回复到达后即使任务已失效或过期，也先记录该回复再停止后续发送；畸形回复不计入，已失效或过期时优先报告取消。结果只代表工作进程确认的请求或完成的 X11 按键派发，不证明目标应用收到、处理或显示文字，未知请求不重放。

取消时 `finished` 可在 worker 回复之前同步发出；其时尚未确认的请求不计入该事件，迟到 ACK 不能追补已发出的统计，也不能据此断言该请求未送达。后端切换或清理中的取消、释放失败及回复异常不授权重试正文。

离线测试覆盖真实 Session 编排配合模拟 worker/受控键盘：原生有效 ACK 后同步取消、回复前取消与迟到回复、失效/过期后的有效或畸形回复、native→XWayland 和 XWayland→native、X→native→X 多作用域、清理等待中真实 task.cancel、清理故障和下一任务重置。相关键盘、路由、Session 和流式输出测试共 434 项通过，Ruff 检查通过。这些测试未运行真实 Wayland 桌面、实际 worker 或目标应用，也不构成 Ubuntu 双系统 AppImage 验收。
