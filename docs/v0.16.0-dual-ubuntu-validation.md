# InkEcho 0.16.0 dual-Ubuntu candidate acceptance

## Artifact and scope

The release-source commit is `eb5536b7e374` (parent `32fbe4a`). The same 104,434,168-byte AppImage, version 0.16.0, SHA-256 `fa1bbfffc6480534b790bdf00e29ea45977f529ef398ceb94fa7f2830223c6bf`, was used in each guest. Package audit reported 3,707 inventory files and 1,048 links verified, 94 application files matching the frozen source, and two WebSocket license copies. Imported application modules came from the mounted AppImage, not the host source tree. The subsequent 0.16.1 commit records evidence; it is not the source of this AppImage.

All guests were isolated VMs, with private test configurations and controlled receiving applications. Protocol exercises used local synthetic HTTP ASR and Qwen VAD WebSocket content. They do not establish real microphone, physical shortcut, authenticated cloud, recognition quality, or performance. No real credentials were used. Test receiver processes terminated by SIGTERM are not evidence of normal application closure.

Xorg IBus has no claimed native bridge. A 24.04 IBus-environment controlled keyboard fallback delivered 22 mixed codepoints and stopped after the first character in the cancellation sample. This does not establish safety during an active IBus composition; simulated key events may change or commit that composition. These controlled samples do not establish universal application support or target-side delivery acknowledgement.

Both operating systems verified package identity in the guest. The GUI probe exercised the actual AppImage and its five pages, single-instance show/quit behavior, cold controls, and preservation of an intentionally damaged isolated config. The local protocol harness exercised the packaged runtime, not live cloud authentication. Input checks used controlled receivers and synthetic keys, and cancellation checks observed no late text in those samples. Focus-switch samples do not establish switching during emission. No clipboard was used by these tests.

## Procedure and failures retained

Build from the frozen source with `python scripts/packaging/build_appimage.py`, compute `sha256sum` on the resulting AppImage, then compare the hash, version, package audit, and module origins inside each isolated desktop. Launch the packaged GUI; run local synthetic protocol, controlled Unicode/partial-cancel and input-method cases in each actual session; record receiver text, active composition, cleanup and session identity. Package and session harness output was retained privately for review; it includes VM state and is not a distributable evidence archive. This summary does not claim those private files will remain available indefinitely.

Initial 24.04 SSH probes timed out while the same VM waited for network initialization; a later probe connected without restarting it. The first 24.04 Fcitx run selected `keyboard-us` instead of pinyin because the guest lacked the Chinese addon; that preedit check failed. A separate no-pinyin run deliberately skipped preedit; its inherited `preedit_verified` flag is invalid and is not counted. Ubuntu noble signed repository metadata and APT package hash checking were used to obtain test-only dependencies. First offline guest installation lacked a language-model dependency and failed; after installing the matching official dependency in a fresh disposable guest, both complete Fcitx runs passed. No host software was installed. Two early 24 Wayland context capture commands also failed because of a wrong output directory; the corrected capture succeeded.

Each test guest reported resource cleanup and exited 0 without OOM. Desktop session and temporary extension settings were restored where changed. The tested Fcitx installations and dependency changes were inside disposable guest overlays. A full source workflow on the release commit passed 2,909 tests with two skipped, in addition to lint and format checks. The workflow does not substitute for untested physical-device, integration/autostart, overlay-focus, actual cloud, or application compatibility checks; these remain unverified for this artifact.
