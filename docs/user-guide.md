# InkEcho 使用指南

本指南描述 2026-10-20 重构后的源码界面：概览、模型配置、风格、设置、帮助。下载包的界面与功能以实际运行版本为准；本次新包尚须完成同 SHA 双 Ubuntu 验收，不能用源码截图替代。历史版本的测试事实保留在各版本报告，当前支持范围见[兼容性矩阵](compatibility-matrix.md)。

开始录音不用先选文本框，录音、识别与润色期间可以切换窗口；结果送到输出当时的光标位置。输出途中切换窗口，后续字符可进入新焦点。主动取消、过期或被替代的任务停止未发送文字，已经发送的按键无法撤回。不使用剪贴板或系统输入法。

## 第一次使用

1. 在「帮助」确认运行版本。若旧实例仍在，先通过托盘菜单正常退出，再启动新包，避免单实例通信只唤起旧实例。
2. 在「模型配置 → 语音模型」新建配置，显式选择服务平台，自己填写显示名称、模型和认证字段后保存。首次安装不预建阿里或 DeepSeek 配置。只有所选平台支持的转写方式可选；未选择平台时转写方式禁用。
3. 「发现模型 / 测试连接」不代表模型具备转写能力。「测试模型能力」会录制三秒并调用云端，可能计费。模型列表过滤纯文本、TTS 等不适合语音的模型；未核实的手动模型不会冒充已验证支持。
4. 需要润色时，在「概览」或「设置」启用云端润色，再到「模型配置 → 润色模型」保存独立配置。关闭润色时，其配置编辑器、概览选择和相关设置灰显；模板仍可离线编辑。
5. 在「风格」选择忠实整理、社交聊天、编程智能体、正式邮件或自己的模板。修改内置模板会另存用户副本，不能覆盖或删除内置原件。云端预览只在启用润色并明确点击后上传，可能计费，结果不持久保存。
6. 在「设置 → 录音与快捷键」选麦克风、测试设备并显式启用快捷键。应用检查 GNOME 绑定冲突，不覆盖其他应用；其他桌面可自行绑定 `--toggle`。麦克风测试只在内存采集，不上传、不保存音频。实际快捷键和输入支持仍取决于桌面会话。
7. 在「设置 → 输入兼容性」检查当前输入后端，需要时启用键盘输入。未经实测的应用不保证兼容。Ubuntu 24.04 GNOME 46 原生 Wayland 缺少所需接口，不能把 Xorg 验收当作原生 Wayland 支持；原生键盘路线也有非 BMP 字符限制。

使用 Qwen 实时模型时，需明确选择对应实时方式，并在录音设置中选择该模型支持的采样率（当前 Qwen 路线为 16 kHz）。仅修改模型名不能代替切换协议。官方实时地址自动派生；界面不再显示可选实时 URL 或请求 JSON。已有配置中的高级参数仍保留，错误或不适用参数会明确报错，不被静默覆盖。自定义实时端点属于高级文件配置，必须提供真实支持的协议，不能把普通 HTTP 网关当作实时接口。

转写与润色请求超时、边润色边输入及润色失败回退在「设置」保存。尚未尝试输入时，可按设置回退识别原文；已经开始输入后失败会停止剩余文字，不整段重复或回退。

## 录音、预览与输入

按快捷键开始录音，再按一次结束并提交识别；默认通过快捷键开始，概览不再提供录音卡片或开始按钮。输出时把光标放在希望接收文字的兼容应用中。文字不会固定送回录音开始时的窗口。

实时方式在录音期间分段发送音频，HTTP 方式在结束后上传完整录音。两者都只把最终确认的识别结果交给润色或键盘输出。Siri 灵感光谱样式可在「设置 → 显示与悬浮提示」选择；当前 Qwen 实时协议可显示内存中的可替换草稿，取消或结束后清空，不将未确认草稿提前输入。HTTP 或未适配 partial 的协议不显示伪实时正文。悬浮窗使用不接收焦点和鼠标穿透标志；各桌面的实际置顶与无抢焦点行为需分别验收。

主动取消可使用托盘菜单、系统通知中的取消或设置窗口底部仅任务期间显示的「取消当前任务」。窗口、光标或选择区变化本身不取消任务。取消发生在输出中时，已发送部分保留；失败不会回退到剪贴板或系统输入法。「按键已发送」不保证每个应用都接受这些按键。

模型、凭据、Prompt 等在任务开始时固定，本次录音期间修改配置影响后续任务。点击关闭会隐藏到托盘；无托盘时最小化保留恢复入口。主窗口没有退出按钮，需退出时使用托盘菜单或 `--quit`，以便正常释放录音、网络和快捷键资源。

## 页面说明

| 页面 | 可用操作 |
| --- | --- |
| 概览 | 选择语音 / 润色配置，今日字符 / 时长 / 次数与最近七天图，显式刷新计费状态；不包含录音控制卡片 |
| 模型配置 | 语音与润色独立配置，平台能力过滤、模型发现、认证保存 / 删除和能力测试 |
| 风格 | 四个内置模板、自定义新建 / 复制 / 编辑 / 删除，明确触发的云端预览 |
| 设置 | 请求超时与润色偏好；录音 / 快捷键、显示 / 悬浮、输入兼容、数据 / 日志、启动 / 桌面集成 |
| 帮助 | 运行版本、手动检查正式版、发布链接与使用提示 |

统计只保存数字，字符按 Unicode 码点计数，不保存转写历史。供应商未返回完整 Token 时显示未知，本地 Token 不等于实际账单。余额刷新仅对已适配的官方接口查询；目前支持 DeepSeek 官方配置，其余显示余额未知并在可识别时提供官方控制台。不会把自定义网关的 key 发送到官方平台。检查更新只读 GitHub 正式版，不自动下载或安装。

## 数据与故障恢复

配置位于 `$XDG_CONFIG_HOME/inkecho`，未设置时为 `~/.config/inkecho`。模型配置与 Prompt 独立保存；全部认证字段明文保存在专用 `credentials.json`（目录0700 / 文件0600），其余 JSON 仍只保存引用。`--config-dir` 使用独立凭据文件。不读取或迁移旧系统密钥环，旧引用缺本地凭据需重新填写。备份 credentials.json 也会备份明文密钥。

统计与诊断默认位于 `~/.local/state/inkecho`（可由 XDG_STATE_HOME 或独立 data-dir 更改）。诊断不记录音频、识别正文、润色正文或密钥。配置损坏、字段不兼容或未来版本时保留原文件并报告问题，不覆盖成默认值；备份后修复再启动。

删除桌面入口不删除配置或凭据。清理某配置的密钥时，在模型配置页点击删除密钥。应用不会默认启用开机自启动。桌面安装、移动 AppImage 后修复路径及自启动在「设置 → 启动与桌面」主动操作。

开发与验证见[开发规范](DEVELOPMENT.md)及[本次界面验证](ui-redesign-validation.md)。
