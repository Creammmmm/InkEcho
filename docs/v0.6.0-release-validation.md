此提交中的 README 指向预定 `v0.6.0` 发布页和附件名，不作为远端完成证明。发布 ID、URL、远端资产下载散列及正式/latest 回读结果后续保存在 `build/release-0.6.0/` 的发布记录中，最终以 GitHub 实际状态为准。未知写操作结果先读状态，不盲目重试。
