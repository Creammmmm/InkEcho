# InkEcho v0.6.0 — 更清晰的配置与实时语音预览

本版整理概览、模型配置、润色风格、设置和帮助页面，并为 API 配置增加中文步骤与平台入口。延续录音启动、实时预览和退出后快捷键行为的修复。

- **概览更直观**：顶行显示今日字符、录音时长与次数，下方为七日字符柱状图和模型配置；已适配余额接口自动查询，无法查询时显示未知及已知平台入口。
- **API 配置有引导**：模型配置中可直接打开对应平台控制台和文档，展开查看获取凭据、选择模型、保存与检查连接的步骤。更换为自定义网关后移除原官方密钥链接；未核实的入口不猜测。引导本身离线，不读取密钥或自动打开网页。
- **润色风格更明确**：卡片展示聊天、编程智能体、正式邮件、忠实整理等模板，详细中文指令要求只整理原文，保留自定义能力。
- **设置更方便**：有效偏好自动保存，快捷键通过实际按键录入；数据和日志分开，帮助显示系统与桌面会话信息。恢复只读启动快捷键健康检查，避免迟到状态覆盖新设置提示。
- **录音与预览修复**：录音不再等待输入授权，保留首批采样；支持的 Qwen 实时协议使用服务端语音检测预览草稿，三种悬浮样式均可显示状态与文字。草稿仅在内存预览，最终文字仍经完整任务确认后输出。
- **退出行为更一致**：关闭设置窗口保留托盘，完全退出后快捷键不会重新启动程序；控制命令采用轻量启动路径。

不使用剪贴板或系统输入法。文字发送到输出当时的光标位置；主动取消、过期或被替代后停止未发送文字，不重放已发送或状态不明的输入。所有平台认证字段继续明文保存在配置目录专用 `credentials.json`，不使用系统密钥环；旧配置与旧版本安装包保留。

## 平台与验证边界

发布目标为 Linux x86_64：Ubuntu 24.04 / GNOME 46 的实测 Xorg 路径，以及 Ubuntu 26.04 / GNOME 50 的原生 Wayland 与 XWayland 限定测试目标。**GNOME 46 原生 Wayland 尚不支持**；不宣称所有应用、所有 Linux 桌面或 Windows/macOS 支持。原生 Wayland 仍保持既有 Unicode BMP 边界，不支持的非 BMP 字符明确拒绝。

确切产品提交、AppImage 散列、双系统验收环境及实际结果以本版独立验收报告与正式附件为准；源码测试、旧版安装包结果与本版实际包验收分别记录。

本地 TLS/WebSocket、合成音频、模拟余额和更新检查不等于真实云账户、模型权限、账单、物理麦克风、物理快捷键或语音准确率认证；本轮没有新增这些实际验证。查看引导无需密钥，实际云端识别与润色仍需自行配置相应平台权限。

下载 AppImage 与同名校验文件后：

```sh
sha256sum -c InkEcho-0.6.0-x86_64.AppImage.sha256
chmod +x InkEcho-0.6.0-x86_64.AppImage
./InkEcho-0.6.0-x86_64.AppImage
```

旧实例运行时，请从托盘正常退出后再启动新版，避免单实例通信只唤起旧版本。
