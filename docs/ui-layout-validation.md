# 工作台布局调整验证（2026-10-21）

## 需求与实现范围

本轮按用户要求重排配置工作台，保留现有录音、转写、润色、模拟键盘输出与
取消语义，不使用剪贴板或系统输入法。用户现有配置、凭据和自定义模板保留。

- 概览：顶行展示今日字符、录音时长和使用次数；下方左右两列分别为七日字符
  柱状图、当前语音与润色配置。余额显示在配置旁，自动读取已适配官方只读接口，
  五分钟内存缓存，配置或凭据变化失效，离开可见概览即停止计时和取消请求。
  未适配平台标明未知并链接已知官方控制台，自定义网关不向官方接口发送密钥。
  窄图表采用「15日」短标签，完整日期和精确数字保留在悬停提示中。
- 模型配置：加宽配置选择，保留保存配置、删除配置和测试连接；移除删除密钥、
  发现模型、云端模型能力测试按钮及重复上传说明。本地模型目录与远端发现明确区分。
- 润色风格：导航与标题采用完整名称；以模板卡片展示标题和简述，查看或编辑详细
  中文模板。模板明确只整理原文，禁止回答口述问题、代执行指令或添加无关说明。
  移除风格下拉选择及润色示例栏，保留内置保护、复制与用户模板功能。
- 设置：首张卡片排列润色开关和请求超时，有效修改自动保存；快捷键改为真实按键
  捕获，保留刷新设备，删除麦克风三秒测试、外观保存、波形预览及多余说明。
  数据与日志独立展示。自动保存与刷新不得回写无关字段或丢失用户修改。
- 帮助与侧栏：更新检查和发布下载入口同行，精简重复说明；侧栏移除首期预览与
  剪贴板说明，在合适位置显示实际检测的系统、桌面及 Wayland/X11 信息，未知不虚构。

完整需求以 [项目规范](PROJECT_SPEC.md) 的 2026-10-21 用户修订为准。
概览的请求边界与聚焦测试见 [概览验证](overview-layout-validation.md)。
