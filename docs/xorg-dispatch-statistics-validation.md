# Xorg 键盘派发统计：取消与失败边界

2026-10-31，对 `KeyboardInput` 的 X11 直接路径增加任务作用域内的按键派发计数。按键按下请求成功返回后、首字回调之前更新计数；同步取消因此可以在 `finished` 发出前读取当前派发下界。分段输出累计在同一作用域内，下一任务重新从零开始。此计数只表示完成派发的下界，不证明目标应用接收、处理或显示文字；按下请求结果未知时不将该次计入，即使目标可能实际收到。释放失败时此前成功的按下仍是派发，不意味着完整按键或目标收件。没有增加重放，也没有改变发送、焦点或取消策略。

离线测试使用受控键盘驱动和真实 Session、路由与流式消费者：首按回调同步取消、按下后异步取消、成功首段后第二段取消、第一或第二段首按回调抛普通异常或 `KeyboardError`，均检查计数、按键释放和清理；未知按下失败不计入、释放失败保留已完成派发数、新任务从零开始。普通异常维持原有异常传播，并附带可用的派发下界供 Session 记录。相关键盘、路由、Session、流式输出测试共 291 项通过，Ruff 检查通过。

此验证不代表物理按键、真实窗口收件确认、原生 Wayland 或 Hybrid 路径的部分派发统计；也未在实际桌面重新验证本次修复。此前 Xorg 客机的取消样本观察到控件已有首字而 Session 报告零，是修复动机，不是本次修改的实际客机验收。
