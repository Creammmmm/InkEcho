# 0.16.7 候选包：IBus 自动键盘回退会改变活动组词

2026-10-31，在隔离 Ubuntu 24.04.5/GNOME 46 和 Ubuntu 26.04.1/GNOME 50.1 的 Wayland 虚拟机会话中，对同一候选 AppImage 执行独立复核。实际包 SHA-256 为 `2d5fcc410bd629e8c32f3c4a52a2b867cc4d567b2fa2f55e1703036da6191cec`，104434168 字节；两客机包审计记录均核对相同 SHA。该实验使用私有 Chrome 配置、自有合成页面和测试文本，不访问用户网页、正文或剪贴板。

## 复现条件与观察

测试使用候选包中的真实自动路由与 owned IBus bridge。先让自建原生 Wayland GTK 窗口 A 获焦并由自动模式选中 owned IBus；夹具仅在第一次实际 insert 调用前暂停。随后切换到自建 XWayland Chrome 窗口 B，在 IBus libpinyin 中输入 `ni` 并观察到活动候选“你”；再恢复首次 insert。被测 bridge 返回 `no_service`、累计尝试 0，自动路由切换到键盘并发送“甲”。

两个系统的 Chrome 页面都记录了先前活动组词的 `compositionupdate(甲)` 和 `compositionend(甲)`，此前的预编辑不再保持；之后测试空格，页面显示“甲你”。因此这不是候选文字必然永久丢失的证明，但已经证明网页感知的组合事件被提前结束，违背活动组词保护要求。取消对照在首字后取消，报告 `input_cancelled`、尝试数 1，第二字未发送，但组词事件此前已结束；取消不能撤销已经发生的变化。

## 对照和限制

Ubuntu 26 的独立自有 GTK XWayland 对照在相同类型的切换下未观察到组词破坏；该单应用结果不能覆盖 Chrome 或其他程序。26 首次 Chrome 实验因隔离 HOME 缺 IBus 地址，`ni` 进入正文而未形成活动组词，不计作有效组词样本；配置隔离地址后 `handoff-browser-r2` 才得到上述结果。Ubuntu 24 的 libpinyin 依赖仅在隔离客户机内安装；两客机恢复了测试修改的输入源、扩展和会话状态，资源检查及 QEMU 退出记录通过。

原始记录位于临时目录 `/tmp/inkecho-0167-ibus-handoff24/output/` 与 `/tmp/inkecho-0167-ibus-handoff26/output/`：分别查看 `handoff-browser-r2/result.json`、`handoff-browser-cancel/result.json`、`wayland/package-audit.json` 和清理记录。复现需要相同候选包、隔离 GNOME Wayland 客机、IBus libpinyin、私有 XWayland Chrome 与原生 GTK 夹具及首次 insert 前暂停；临时目录不是永久发布资产。此处不涉及真实云、物理麦克风或快捷键，不证明任意应用都出现相同事件。

**结论：0.16.7 候选包存在已实测的组词保护缺陷，不得作为安全验收通过或据此发布。** 这份记录及随后的 0.16.8 版本号仅记录缺陷，不表示缺陷已经修复，也不构成 0.16.8 AppImage 验收。
