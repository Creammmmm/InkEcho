# InkEcho

InkEcho 是一个以跨平台为目标的桌面语音转文字开源应用项目，首期面向 Linux。

计划提供全局快捷键录音、云端语音识别、可选文字润色，以及向目标窗口直接输入文本的能力，默认不使用剪贴板。

## 项目状态

目前处于需求与技术可行性验证准备阶段，尚无可运行应用。首期计划验证 Ubuntu 的 X11 / Wayland 环境；Windows 和 macOS 为后续适配方向。具体兼容性以实际测试结果为准。

## 开发入口

- [项目规范](docs/PROJECT_SPEC.md)：需求、架构约束、实施阶段与验收标准。
- [Agent 开发指引](AGENTS.md)：开发前必读入口。

计划使用 Python、PySide6 和 pytest，首期以 AppImage 分发。开发应先完成规范中的阶段 0，重点验证无剪贴板中文及 Unicode 输入的可行性。
